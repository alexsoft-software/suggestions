# Self-Reading PHP Program

Αυτό το PHP snippet εκτυπώνει τον δικό του πηγαίο κώδικα.

### Λειτουργία:
- **`file_get_contents(__FILE__)`**: Διαβάζει το περιεχόμενο του τρέχοντος αρχείου PHP.
- **`htmlentities()`**: Μετατρέπει ειδικούς χαρακτήρες σε HTML οντότητες για ασφαλή εμφάνιση.
- **`echo`**: Εκτυπώνει το αποτέλεσμα μέσα σε ετικέτα `<pre>` για διατήρηση μορφοποίησης.

### Χρήση:
Εμφανίζει τον κώδικα του ίδιου του script στο πρόγραμμα περιήγησης.
